# USA-Housing-Insights

## Project Overview
This project performs Exploratory Data Analysis (EDA) on the USA Housing dataset using Python. The objective is to understand housing price trends, identify important factors affecting house prices, and visualize relationships between variables.

## Dataset Description
The dataset contains information about housing characteristics and their corresponding prices in different regions of the United States.

### Features
- Avg. Area Income
- Avg. Area House Age
- Avg. Area Number of Rooms
- Avg. Area Number of Bedrooms
- Area Population
- Price (Target Variable)
- Address

## Objectives
- Explore the structure of the dataset.
- Perform data cleaning and preprocessing.
- Analyze distributions of housing features.
- Detect and handle outliers.
- Study relationships between variables.
- Visualize correlations using heatmaps and scatter plots.

## Tools and Libraries Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Analysis Performed
### Data Preprocessing
- Checked for missing values.
- Verified data types.
- Removed unnecessary columns where required.
- Handled outliers using statistical methods.

### Univariate Analysis
- Histograms
- Boxplots
- Distribution plots

### Bivariate Analysis
- Scatter plots between housing features and price.
- Regression plots for trend analysis.

### Multivariate Analysis
- Correlation heatmap.
- Feature relationship analysis.

## Key Insights
- Area income shows a strong positive relationship with house prices.
- Population and number of rooms moderately influence housing prices.
- Higher-income regions generally have more expensive houses.
- Correlation analysis helps identify the most influential housing factors.
